じゅんび

  1. スマホの「設定 → Bluetooth」を開き、Switchのコントローラーのシンクロボタン（Joy-Conは側面のレール部、Proコンは上面の小さい丸ボタン）を長押ししてペアリングします。
  2. このページに戻り、コントローラーのボタンを1回押します（上の表示が緑になります）。
  3. コースを選び、画面の白い枠にミニカーを置きます。枠の大きさは L / R ボタンか画面下のボタンで合わせられます。

そうさ

左スティック / 十字 ←→ハンドル（画面がうごきます）
A・B・ZR / スティック↑アクセル
Y・ZL / スティック↓ブレーキ・バック
Xクラクション
L / Rミニカーの枠サイズ調整
こうそくどうろ左はしの「出口」レーンに入ると、まちへ行けます。料金所は、ゆっくり通ると⭐ボーナスです。
がめんの ボタンコントローラーがないとき用。◀▶でハンドル、アクセル・ブレーキ、📢クラクション（コントローラーをつなぐと自動で消えます）
＋ / −メニューにもどる

ブロックづくり（くるまは でません）

  • 画面の左の丸（またはコントローラーの左スティック）で歩き、ジャンプで1段の段差を越えられます。画面をドラッグ（または右スティック）でカメラが回ります。
  • 道に沿って並んだ色つきボタン（58しゅるい: おしろ・タワー・いえ・にわ・かいだん・はし・プール・ふんすい、いっこだて・マンション・コンビニ・がっこう・びょういん・えき・じんじゃ・ごじゅうのとう・かんらんしゃ・スタジアム など）を踏むと、すぐ後ろの色のついた予定地に、それが出てきます（カメラが予定地を映します）。一度つくったものは、そのまま残ります。道は8本あり、列ごとに、住宅・お店・公共・ビル・名所・レジャー・のうじょう の順です。
  • 上の色の丸（コントローラーは L / R）でブロックの色を選ぶと、そのあとに建つ建物の色が変わります。
  • ボタンは、ボタンとボタンの間を通れば、踏まずに歩いて出られます。
  • 作ったものは、この端末に自動で保存されます。

ちゅうい

  • 画面にキズがつかないよう、保護フィルムを貼ったスマホで、そっと置いてください。
  • スマホは平らな机の上に置いてください。金属のミニカーが画面に反応することがあるため、走行中に反応するのは画面下の操作ボタンだけにしています（ミニカーを置く場所や、メニューへの戻りは右上の長押し）。
  • コントローラーがない場合はキーボード（矢印キー / スペース）でも動かせます。
